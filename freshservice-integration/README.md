# Freshservice ITSM Integration

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white)
![Freshservice](https://img.shields.io/badge/Platform-Freshservice-green?style=flat-square)

Full Freshservice ITSM integration pipeline with five composable Python modules covering the complete API surface. Supports ticket lifecycle management, asset tracking, agent and group operations, change requests, problem management, and release coordination.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Features

- Complete ticket lifecycle: create, query, update, close, reassign, escalate
- Ticket notes and conversation thread management
- Asset inventory querying and association
- Agent and group listing and assignment
- Change request, problem, and release management
- Composable module architecture for selective integration

## Directory Structure

```
freshservice-integration/
|-- modules/             # Five composable API modules
|-- config/              # Connection and authentication configuration
|-- templates/           # Ticket and notification templates
|-- tests/               # Integration test suite
|-- README.md
```
