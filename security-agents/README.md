# Security Tool Agent Builder

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white)
![AI](https://img.shields.io/badge/Domain-AI%20Agents-purple?style=flat-square)

Framework for building vendor-specific security tool SME agents with comprehensive knowledge bases. Produces specialized AI agents that help security teams navigate, query, triage, and remediate across their security tool stack.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Features

- Vendor-specific agent generation for major security platforms
- Knowledge base construction from vendor documentation and runbooks
- Platform coverage: Splunk, Arctic Wolf, SentinelOne, Palo Alto, Darktrace, SecurityScorecard, Microsoft Purview
- Triage workflow encoding for common alert types
- Remediation playbook integration
- Agent evaluation and accuracy validation

## Directory Structure

```
security-agents/
|-- builders/            # Agent construction framework
|-- knowledge/           # Vendor-specific knowledge bases
|-- templates/           # Agent instruction templates
|-- evaluations/         # Agent accuracy test suites
|-- README.md
```
