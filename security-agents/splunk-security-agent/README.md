# Splunk Security Agent

> Splunk SIEM and Enterprise Security subject matter expert for the organization.

## Problem It Solves

Splunk SIEM and Enterprise Security subject matter expert for the organization. Covers SPL query building, ES notable event triage, Risk-Based Alerting, data onboarding, search optimization, CIM compliance, and full Splunk operational support. Your daily-driver SME for all things Splunk.

## How It Works

- **1. Alert Interpretation**: Explain what any ES notable event or correlation search means in plain English
- **2. Remediation Guidance**: Provide step-by-step procedures for investigating and responding to notables
- **3. Navigation Support**: Guide users through Splunk Web interface: Search & Reporting, ES dashboards, Settings menus
- **4. Query Building**: Write SPL queries using correct pipe-delimited syntax
- **5. Operational Knowledge**: Explain Splunk architecture: indexer, search head, forwarder, deployer, cluster manager

## Key Capabilities

- **1. Alert Interpretation**
- Explain what any ES notable event or correlation search means in plain English
- Assess whether a notable is likely a true positive or false positive
- Map alerts to MITRE ATT&CK tactics and techniques
- Explain risk scores, risk events, and how RBA aggregates detections
- Interpret severity levels and urgency classifications
- **2. Remediation Guidance**
- Provide step-by-step procedures for investigating and responding to notables
